Screenshots are in [img/](img). The posts reference them at
`https://raw.githubusercontent.com/mojimoon/vndb/main/docs/announcement/img/…`,
so the links work once this folder is on `main`. Bangumi renders `[img]`;
VNDB's forum BBCode has no image tag, so the VNDB posts link the screenshots
with `[url]` instead.

Before posting:

* Check the numbers in the posts against the current Stats page
  (titles, votes, users, methods); they were written for the 2026-10-06 dump.
* VNDB only allows linking external sites in forum posts that are relevant to
  VNDB; the posts credit the data source and licence (ODbL) as required.
